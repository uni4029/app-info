利用条件

最終更新日：2026年11月9日

Phrase Finch Studioは、運営者本人の語学教材の保存・投稿・分析を支援する作業ツールです。一般向けのアカウント登録や利用者募集は行っていません。

利用と公開の判断

本人が利用権限を持つ教材とアカウントのみを扱います。YouTubeでの公開範囲と公開日時は、本人の指示および本人が定めた品質確認・運用方針に沿って決めます。公開した動画の権利や内容については、投稿者が確認します。

外部サービス

本アプリはYouTube API Servicesを使用します。本アプリを利用することで、利用者はYouTube利用規約に拘束されることに同意するものとします。Google Drive等の外部サービスを利用する際には、それぞれの利用条件も適用されます。

データの取り扱い

本アプリの機能を利用する前に、プライバシーポリシーを確認し、内容に同意してください。連携解除と削除方法はデータ管理の案内に記載しています。

動作と計測値

外部APIの制限、認可の失効、処理待ち、通信障害により、一部の操作や計測が完了しない場合があります。処理状態と実際の公開・保存状態を照合し、未取得の値を実測ゼロとして扱わない運用を行います。

問い合わせ

GitHub Issuesへ概要をご連絡ください。投稿は一般公開されます。個人情報、非公開教材、認証情報を記載しないでください。
