プライバシーポリシー

最終更新日：2026年11月9日

Phrase Finch Studio（以下「本アプリ」）は、uni4029が語学教材の制作・投稿・分析のために個人で運用するツールです。本アプリがGoogleとの連携で扱う情報について説明します。

取得する情報と利用目的

  • Google Drive：本人が認可した教材のファイル内容、ファイル名、識別子、種類、親子関係、サイズ、更新情報などを、教材の確認・保存・編集・アップロードに利用します。Driveの読み書き権限はGoogle側ではDrive全体を対象としますが、本アプリは操作対象を指定フォルダ「Listening Notes」とその配下に制限します。
  • YouTube：チャンネル情報、動画や再生リストの情報、動画の公開状態・予約情報、視聴回数や視聴分析データを、教材の投稿、公開管理、結果の確認に利用します。本人の指示に応じて、動画のアップロード、公開予約や再生リストへの追加を行います。
  • 認証情報：Google連携の維持に必要なアクセストークンや更新トークンを取り扱います。

保存と外部サービス

教材ファイルは本人のGoogle Driveで管理し、投稿の状態や測定結果などは本アプリに記録します。本アプリの実行にはOpenAIのSitesとCloudflareを使用し、Drive・YouTubeへのアクセスにはGoogleのサービスを使用します。本人がChatGPTを使って本アプリを操作する場合、操作に必要なデータがChatGPTで処理されます。各サービスでのデータの保持は、それぞれの設定と提供元の規定に従います。

Googleから取得したデータは本アプリの機能のために利用し、販売、広告配信、汎用AIモデルの開発・学習を目的として利用・転送しません。本アプリによるGoogle APIからの情報の利用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

データの削除と連携解除

Drive上の教材やYouTube上の動画は、それぞれのサービスで削除できます。Driveのゴミ箱への移動だけでは完全には削除されません。本アプリに記録されたデータや保存済み認証情報の削除は、下記窓口へお問い合わせください。各サービスのバックアップなどの保持は、各提供元の規定に従います。

Googleアカウントの接続管理から本アプリのアクセス権を削除できます。連携解除後は新たなGoogleデータへのアクセスができなくなりますが、取得済みのデータ、Driveのファイル、YouTubeの動画は自動削除されません。
