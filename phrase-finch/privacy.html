アプリ一覧アプリ紹介プライバシー利用条件

プライバシーポリシー

最終更新日：2026年11月9日

Phrase Finch Studio（以下「本アプリ」）は、uni4029が本人の語学教材の制作・保存・投稿・分析のために運用するツールです。本アプリで扱う情報について説明します。

1. 取得する情報

  • Google Drive：本人が認可したアカウントの識別情報と、指定フォルダ内のファイル名、種類、親子関係、識別子、更新情報、サイズ、チェックサム、必要なファイル内容。
  • YouTube：本人のチャンネル・動画・再生リストの識別情報、タイトル、公開状態、公開・予約日時、字幕・サムネイルの処理状態、再生数、視聴維持率などAPIから取得できる視聴分析情報。
  • 認可・処理記録：OAuthの更新トークン、処理中に使用するアクセストークン、アップロードの再開情報、教材の版、検査結果、投稿・計測の進捗。

本アプリはYouTube API Servicesを利用します。Googleによる情報の取り扱いはGoogleのプライバシーポリシーもご確認ください。

2. 権限と対象範囲

Drive読み取りには drive.readonly、保存・編集には drive、YouTube投稿管理には youtube.force-ssl、視聴分析には youtube.readonly と yt-analytics.readonly を、必要な用途ごとに要求します。これらはGoogleのOAuthスコープです。

Google側のDrive権限はアカウント内の広い範囲を対象にします。本アプリでは操作時にフォルダの親子関係を確認し、指定フォルダとその配下に対象を制限します。YouTube操作では設定済みの本人のチャンネルとの一致を確認します。

3. 利用目的

教材の素材管理、版の照合、アップロードの再開、字幕・サムネイルの添付、公開・予約公開・再生リストの管理、視聴状況の確認と教材改善に使用します。処理は本人の操作、指示、または本人が設定した継続的な運用方針に沿って行います。

Googleから取得した情報を販売したり、広告配信や汎用AIモデルの開発・学習を目的に利用・転送したりしません。本アプリによるGoogle APIからの情報の利用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

4. 保存先と外部サービス

教材ファイルと制作記録は本人のGoogle Driveに保存します。YouTubeにアップロードした動画と添付情報は、本人が指定した公開設定でYouTubeに保存されます。アプリの設定、暗号化した認可情報、処理の再開情報、教材の登録・検査・公開・計測記録は、作業アプリのデータベース（Cloudflare D1）で管理します。

Google APIへのアクセスにはGoogle、作業アプリの提供にはOpenAIのSitesとCloudflare、本人が依頼する企画・確認・分析や操作にはOpenAIのChatGPTを利用します。これらの処理に必要な範囲のファイル内容や結果が各サービスで扱われる場合があります。ChatGPT側の会話やデータの保持は、利用プラン・設定と提供元の規定に従います。

教材制作で音声・画像の生成サービスを利用する場合は、本人が選んだ制作手順に従って必要な台本や生成指示を渡します。Googleの認証情報をこれらの制作サービスへ渡しません。

5. 安全管理

作業アプリへのアクセスを所有者に制限し、通信にはHTTPSを使用します。更新トークン、クライアントシークレット、アップロードの再開に使うGoogle側のURLはサーバー側で暗号化して保存します。これらの認証情報を本公開ページに掲載しません。

6. 保持・削除と連携解除

教材と制作履歴は、本人が教材の管理と改善に必要とする期間保持します。YouTubeから取得した情報は、取得時点を区別して利用し、YouTubeの規定に従って認可の継続確認、更新、削除を行います。

Googleとの連携はGoogleアカウントの接続管理から解除できます。アプリ内の保存済みデータの削除を希望する場合は、下記窓口へ概要をご連絡ください。運営者が対象を確認し、法令および適用されるAPIの規定に従って対応します。

Google Drive上の教材、YouTube上の動画、アプリのデータベース、ChatGPTの会話は保存先が異なります。一つの保存先で削除しても、他の保存先から自動的にすべて削除されるわけではありません。詳しくは連携解除とデータ削除をご確認ください。

7. この公開サイト

この公開サイトはGitHub Pagesでアプリ紹介とポリシーを掲載するためのものです。認証・ファイル送信・広告・アクセス解析のための独自スクリプトや入力フォームを設置していません。ページ配信に伴う通信情報は、ホスティング提供元のGitHubで処理されます。外部リンクを開いた先では、各サービスの規定が適用されます。
