プライバシーポリシー

最終更新日：2026年11月9日 · ポリシー版：2026-11-09.1

Phrase Finch Studio（以下「本アプリ」）は、uni4029が語学教材の制作・投稿・分析のために個人で運用するツールです。本アプリがGoogleとの連携で扱う情報について説明します。

本アプリはYouTube API Servicesを使用します。Googleによる情報の取り扱いについてはGoogleのプライバシーポリシーもご確認ください。本アプリの利用条件にはYouTube利用規約へのリンクを記載しています。

取得する情報と利用目的

  • Google Drive：本人が認可した教材のファイル内容、ファイル名、識別子、種類、親子関係、サイズ、更新情報などを、教材の確認・保存・編集・アップロードに利用します。Driveの読み書き権限はGoogle側ではDrive全体を対象としますが、本アプリは操作対象を指定フォルダ「Listening Notes」とその配下に制限します。
  • YouTube：チャンネル情報、動画や再生リストの情報、動画の公開状態・予約情報、視聴回数や視聴分析データを、教材の投稿、公開管理、結果の確認に利用します。本人の指示に応じて、動画のアップロード、公開予約や再生リストへの追加を行います。
  • 認証情報：Google連携の維持に必要なアクセストークンや更新トークンを取り扱います。

保存と外部サービス

教材ファイルは本人のGoogle Driveで管理し、投稿の状態や測定結果などは本アプリに記録します。本アプリの実行にはOpenAIのSitesとCloudflareを使用し、Drive・YouTubeへのアクセスにはGoogleのサービスを使用します。本人がChatGPTを使って本アプリを操作する場合、操作に必要なデータがChatGPTで処理されます。各サービスでのデータの保持は、それぞれの設定と提供元の規定に従います。

Googleから取得したデータは本アプリの機能のために利用し、販売、広告配信、汎用AIモデルの開発・学習を目的として利用・転送しません。本アプリによるGoogle APIからの情報の利用および他のアプリへの転送は、Limited Use要件を含むGoogle API Services User Data Policyに従います。

保存期間と同意の記録

教材と制作記録は、本人の教材管理に必要な期間保持します。YouTubeから取得したデータは取得時点を区別し、種類に応じて更新・削除します。認可を受けた過去の統計を30日を超えて保持する場合は、30日ごとに認可の継続と対象動画の存在を確認します。その他の保存したAPIデータは、適用される規定に従って30日以内に更新または削除します。

ポリシーへの同意について、本人の明示操作により、本人の識別、同意した文書の版、同意日時を記録します。過去の利用を新しい文書への同意とは見なしません。保存データを削除した後も、同意・停止・削除対応の確認と再取り込み防止に必要な最小限の記録を保持します。

データの削除と連携解除

所有者として作業アプリにサインインし、「データ管理」で対象と影響を確認して操作します。Google連携の解除とSite内の保存データ削除は、別々の操作として表示します。

  • Google連携全体の解除：データ利用を停止し、本アプリのGoogleへのアクセス権の解除を要求します。Google側の解除は、該当するGoogleユーザーが同じGoogle Cloudプロジェクトに許可した全スコープ・クライアントの連携に影響します。結果画面で解除の成否を確認してください。この操作だけではSite内の保存データは削除されません。
  • Site内の保存データ削除：確認画面に表示する、保存済みのGoogle認可情報、アップロードの再開情報、教材の登録・検査・投稿・予約・計測記録、制作工程・費用の記録などを削除します。削除後もデータ利用を停止します。Google側のアクセス権解除とは別に、削除結果を確認できます。

実行中または結果を確認できない作業がある場合は、停止状態で解除・削除を保留し、対象を案内します。通信失敗や失効した認可情報への応答を、Google連携全体の解除完了とは扱いません。一つの用途の解除が他の用途も無効にするため、応答が未確認になる場合もあります。未確認と表示された場合は、Googleアカウントの接続管理で対象アプリの連携状態を本人が確認してください。

所有者とOAuthクライアントのアプリ設定、同意・停止・削除結果の最小記録、適用済みの移行記録は保持します。再開には「データ管理」での本人の明示操作と、新しいGoogle認可が必要です。再開を指示すると古い保存済みのGoogle接続情報を消し、新しい認可が完了するまで停止を続けます。ポリシーへの同意だけでは再開しません。

これらの操作では、Google Driveの教材・音声・動画等の原本、YouTube上の動画・再生リスト、ChatGPTの会話を削除しません。YouTubeで設定済みの公開予約も取り消しません。原本の削除や公開予約の変更が必要な場合は、それぞれのサービスで別途行ってください。Driveのゴミ箱への移動だけでは完全には削除されません。

本アプリ内での連携解除または保存データの削除依頼を受けた場合、対象の保存データを速やかに、遅くとも7日以内に削除します。Google側の連携状態も定期的に確認し、Googleの接続管理から解除された場合の関連データは、速やかに、遅くとも解除から30日以内に削除します。一時的な通信障害を認可解除と決めつけてデータを削除することはありません。

Googleアカウントの接続管理からも本アプリのアクセス権を削除できます。Googleでの解除だけでは、Driveの原本やYouTubeの動画そのものは削除されません。本アプリの削除操作を利用できない場合は、下記窓口へ削除希望の概要をご連絡ください。各サービスのバックアップなどの保持は、各提供元の規定に従います。
