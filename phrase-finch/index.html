語学教材の制作・投稿・分析

Phrase Finch Studio

教材の素材を整理し、公開までの進捗を確認し、
次の学習コンテンツに生かすために。

Phrase Finch Studioは、運営者本人が語学教材を管理するための作業ツールです。Google Drive上の動画・音声・字幕・制作記録を整理し、本人のYouTubeチャンネルへの投稿と予約公開、公開後の視聴データの確認を支援します。

このページはアプリの紹介・ポリシーを掲載する公開ページです。教材の原本、非公開動画、制作記録、認証情報は掲載しません。作業アプリの利用は所有者に限定しています。

主な機能

  • 指定したGoogle Driveフォルダ内での教材ファイルの保存・取得・更新と、保存結果の確認。
  • 教材の版・字幕・サムネイルを確認したうえでのYouTube非公開アップロード。
  • 本人の指示と確認済みの公開計画に沿った公開・予約公開・再生リスト管理。
  • YouTube API Servicesによる公開状況・再生数・視聴データの取得と、取得時刻を含む記録。

Googleとの連携

Google Driveの読み取り、ファイルの保存・編集、YouTubeの投稿管理、視聴分析を用途別に認可します。Driveの保存・編集ではGoogle側にDrive全体の権限を要求しますが、アプリ側で操作対象を指定フォルダとその配下に制限します。

ChatGPTからの操作や定期処理にも、本人が許可した用途と対象範囲を適用します。データの取得、保存、外部サービスでの処理、連携解除についてはプライバシーポリシーをご確認ください。
